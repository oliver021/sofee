# Team map and who to ask

Teams change people, so this lists roles and channels. Each team keeps the name of its current owner
on its own wiki page.

## Teams

| Team          | Looks after                                              | Channel          |
| ------------- | -------------------------------------------------------- | ---------------- |
| Platform      | Deployments, on-call, infrastructure and the event bus   | #platform        |
| Orders        | Customer orders and their API                            | #orders          |
| Accounts      | Identity, sessions, roles and test access                | #accounts-help   |
| Notifications | Emails and alerts                                        | #notifications   |
| Data          | Faro, data contracts and dashboards                      | #data-help       |
| Security      | Review of permissions, secrets and authentication        | #security        |

## Frequently asked questions

- **I want to deploy something I cannot see in the pipeline:** Platform, in #platform.
- **There is an on-call alert:** the #on-call channel, and then #incidents if needed.
- **I do not have access to a table:** Data, in #data-help.
- **I do not know whether a change needs a Security review:** Security, in #security. Ask before merging.
- **I want to propose an architecture decision:** write a new ADR from the template and ask Platform for a review.

## Where to ask without fear

The #new-hire-questions channel exists for that. No question from someone who is just starting is a bad question.
