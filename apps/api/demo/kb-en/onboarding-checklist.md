# Onboarding checklist

For anyone joining the team. Each item has an owner who can help you: ask in #new-hire-questions if
you do not know who to go to.

## First day

- [ ] You have an email account, repository access and access to the password manager.
- [ ] You are in the channels #platform, #incidents, #on-call and #new-hire-questions.
- [ ] You have read the [architecture overview](architecture-overview.md) and the [glossary](glossary.md).
- [ ] You have a 30-minute meeting with whoever leads your team.

## First week

- [ ] You have set up the local environment following the main service's README.
- [ ] You have read [how a service is deployed](deploying-a-service.md) and [code reviews](code-reviews.md).
- [ ] You have done your first code review, even if only of a document.
- [ ] You have read the team's first two [ADRs](adr-0007-message-queue.md).

## First month

- [ ] You have had your first change merged into the main branch.
- [ ] You have shadowed two [on-call](on-call.md) rotations.
- [ ] You have read the [March postmortem](postmortem-queue-outage-2026-03.md) and know what changed afterwards.
- [ ] You know who to go to for each topic in the [team map](team-map.md).
